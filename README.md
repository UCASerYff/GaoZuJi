# 搞足迹 V4.03

独立 macOS 应用，包含本模块完整业务、游戏场景和 WidgetKit 小组件。运行不依赖搞七廿三或其他六个应用；联动功能需要同时安装相关应用。

## 下载与安装

从 [Releases](https://github.com/UCASerYff/GaoZuJi/releases/latest) 下载 `GaoZuJi-4.03.zip` 和同名 `.sha256` 文件。仓库保存源码，安装包作为 Release 附件单独发布。

1. 支持 macOS 14 或更高版本、Apple Silicon；暂未提供 Intel 版本。
2. 解压 ZIP，将 `搞足迹.app` 拖入“应用程序”文件夹。
3. 如果 macOS 拦截打开，请先确认软件来源，再进入“系统设置 → 隐私与安全性”，允许该应用打开。发行包使用 Apple Development 签名，未做 Apple 公证。
4. 安装后运行一次，再从系统小组件列表添加本应用的小组件。整合版的小组件需要重新添加。

下载后可在文件所在目录运行 `shasum -a 256 -c GaoZuJi-4.03.zip.sha256` 核验安装包。校验文件名包含中文，命令行请给文件名加引号。

## 功能

- 记录旅行与到访城市，保存照片附件，查看国内和世界地图。
- 设置一个常驻城市：侧栏、设置或城市档案均可设置、更换和清除，地图与小组件使用独立家园标记；支持撤销，完整备份会保存常驻城市。常驻标记不自动增加到访次数、旅行统计或列车奖励。
- 旅行列车包含行驶场景与路线地图；车厢升级、旅行任务与足迹进度联动。
- 内置离线地理数据，来源和许可见 Resources/THIRD_PARTY_NOTICES.txt。

- 从菜单或 ⌘, 打开设置，提供外观、模块设置、备份与恢复。
- 提供本应用对应的桌面/通知中心小组件。


## V4.03 安装入口

旧程序在移出正式安装位置前精确注销，回退副本从生成时放入 `rollback.noindex/`，避免作为第二个可搜索的应用入口；失败时从该副本恢复正式安装。构建、打包及安装暂存均使用 `.noindex` 容器。

## V4.02 小组件同步

- 统计、中国地图与世界地图改为 `widget-generation.json` 单包，包含同一代标识、内容摘要和两张 PNG；校验后原子替换，并保留上一完整代。扩展不再拼接旧的三个独立文件。
- 业务内容指纹及程序版本决定是否重发；仅打开应用或跨日不会虚构资料修改时间。发布失败保留有效包，应用仍运行时按 30 秒、2 分钟、10 分钟、之后 30 分钟退避重试，成功后仅请求本应用 widget kind 刷新。
- 开始运行、重新激活、唤醒、时区/时钟/日期事件及退出时尝试同步。关闭窗口后协调器仍存活；完全退出后扩展继续读取最后有效包，未发布内容待下一次主程序运行补发，不声称退出后仍后台渲染。
- Timeline 只返回当前读取内容；15 分钟是向系统提出的调度建议，不保证固定延迟。保留真实资料时间、发布时刻、请求时刻与读取时刻；`widget-diagnostics/` 中的有限回执只证明扩展读取，不证明桌面已经显示。
- 目前唯一组件 `com.gaoseries.GaoZuJi.widgets.map` 支持中号；多个实例共享完整代，点击链接按当前显示范围打开主程序地图。
- 缺失、损坏或过新 schema 的已有资料库停止写入；不会当作新资料库发布伪造零值。合法清空全部足迹仍能发布真实零记录。

无界面升级发布器由 `scripts/build_widget_publisher.sh` 构建，必须在主程序退出后显式运行。它只读已存在的主库和安装资源，并写 App Group 衍生快照；不启动应用、不修改业务记录。使用时传入已安装 `.app`、真实资料目录和对应 App Group 路径。

验证脚本：`scripts/test_repository_safety.sh`、`scripts/test_widget_generation.sh`、`scripts/test_widget_publisher.sh`、`scripts/test_resident_city.sh`。它们使用隔离临时目录，不启动应用或窗口。实际桌面显示、睡眠/重启、多实例与点击响应需在用户授权的实际验收中核对，不以单元测试通过替代。

## 用户数据、附件与隐私

源码及安装包不包含个人记录、账户配置、账单、健康数据、私人附件、API 密钥、浏览器会话或用户备份。新电脑首次打开时创建自己的资料库；GitHub 下载不能恢复个人数据。

- 业务数据目录：`~/Library/Application Support/GaoSeries/Footprints/`。
- 数据库或小组件镜像：`~/Library/Group Containers/5G96498KGJ.com.gaoseries.GaoZuJi/`。
- 设置保存在本应用的 UserDefaults 域；凭据由 macOS 钥匙串管理，不导出到普通备份文件。
- 公开安装包会删除本机编译路径、源文件索引及扩展属性，再重新签名。签名证书的公开身份信息随软件发布，签名私钥不在仓库或安装包中。

真实业务历史完整保留。界面采用分页或归档减轻加载；游戏事件最多保留 300 条、抽取记录最多 200 条、词元账户显示采样最多 300 条，累计收益、余额、保底计数、库存与游戏进度独立保存。

## 数据迁移与恢复

V4.01 在原 SQLite 数据路径中增加可选的常驻城市字段，旧资料升级后默认为未设置，不推测居住地。所有原足迹、附件、设置和列车进度继续保留；兼容此前模块备份及完整资料 ZIP。

V4.0 从整合版拆分时保留业务历史、余额、库存、游戏进度、设置和全部附件。独立应用继续使用各自的数据目录，升级或替换应用程序不会删除这些数据。

在设置的数据页导出“完整资料 ZIP 备份”。恢复备份可迁移本应用的资料、App Group 镜像、设置以及已管理的 PDF、Word、照片等附件。备份使用逐文件 SHA-256 校验与 SQLite WAL 一致快照，恢复前保存安全副本；待下次启动应用时应用恢复。备份必须来自同一应用，不能将另外一个模块的备份直接导入。钥匙串凭据需在新电脑重新配置。

迁移临时副本不属于程序运行依赖，确认数据与附件完整后可自行清理。个人备份应单独保管，不应放进源码目录或上传公开仓库。

## 从源码构建

需要完整 Xcode、Python 3 和 Apple Silicon Mac。默认脚本使用项目配置的开发签名身份；自行构建需使用自己的 Apple Development 证书，并相应调整签名团队、App Group 权限及小组件工程配置。

```sh
./scripts/build.sh
./scripts/package.sh
./scripts/install.sh
```

通过环境变量 `GAO_SIGNING_IDENTITY` 可指定签名证书。修改团队后也需调整 `scripts/install.sh` 中的团队检查。`dist/` 存放本地发行 ZIP 和校验文件，不提交到 Git；上传到 GitHub Releases。

- `Sources/`、`Shared/`（如有）与 `Module.swift`：业务和游戏逻辑。
- `GameWorld/` 与 `Resources/`：场景、模型、贴图和其他资源。
- `Host/`：独立入口、设置、完整备份和联动服务。
- `WidgetExtension/`：小组件；`Tests/`：回归验证。

## 版本更新

版本以 `Info.plist` 为准。后续功能改动仅更新受影响的应用，默认版本 +0.01、构建号 +1；明确要求保持版本号的修订沿用原版本。先核验用户资料，再安装新程序并检查记录、附件和游戏进度，成功后清理旧程序、安装包与中间构建。程序资源与用户资料须分别处理，不能用清理构建目录的方式删除用户数据。

第三方组件和资源保留各自许可，详情见 `Resources/` 中的许可、来源说明与补丁记录。
